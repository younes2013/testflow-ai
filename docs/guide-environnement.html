Guide de préparation de l'environnement de développement
Windows 10/11 — Stack : ASP.NET Core 8 · React · SQL Server · Ollama

Ce guide vous permet de préparer votre poste de travail Windows pour développer et tester le projet TestFlow AI au fur et à mesure de l'avancement. Suivez les étapes dans l'ordre.

ℹ️ Prérequis matériel recommandé : 16 Go de RAM (8 Go minimum), 20 Go d'espace disque libre, connexion Internet pour les téléchargements initiaux.

1 — Git

Vérifier si Git est déjà installé :

git --version
# attendu : git version 2.x.x

Si Git n'est pas installé, télécharger l'installeur Windows : https://git-scm.com/download/win
Installer avec les options par défaut.

Configurer votre identité

À faire une seule fois — ces informations apparaîtront dans chaque commit :

git config --global user.name "younes2013"
git config --global user.email "hadariyounes@gmail.com"
git config --global core.autocrlf true   # important sur Windows

2 — .NET 8 SDK

Télécharger le SDK .NET 8 : https://dotnet.microsoft.com/download/dotnet/8.0

Choisir .NET 8.0 SDK (x64) → installer avec les options par défaut.

Vérifier l'installation :

dotnet --version
# attendu : 8.x.x

Installer les outils Entity Framework Core

dotnet tool install --global dotnet-ef
dotnet ef --version
# attendu : Entity Framework Core .NET Command-line Tools 8.x.x

3 — Node.js 20+

Télécharger la version LTS : https://nodejs.org
Choisir Node.js 20 LTS → installer avec les options par défaut.

Vérifier :

node --version   # attendu : v20.x.x ou supérieur
npm  --version   # attendu : 10.x.x

4 — Docker Desktop (SQL Server Express)

Télécharger : https://www.docker.com/products/docker-desktop/

⚠️ WSL 2 requis. Lors de l'installation, Windows peut vous demander d'activer WSL 2. Accepter et redémarrer si demandé. Docker Desktop ne fonctionnera pas sans WSL 2 sur Windows 10/11.

Vérifier après installation :

docker --version
docker compose version

Démarrer SQL Server Express

Depuis le dossier racine du projet testflow-ai/ :

# Démarrer le conteneur SQL Server en arrière-plan
docker compose up -d

# Vérifier que le conteneur est en cours d'exécution
docker ps

Tester la connexion à SQL Server

docker exec -it testflowai-sqlserver /opt/mssql-tools18/bin/sqlcmd ^
  -S localhost -U sa -P "TestFlowAI@2024!" -C -Q "SELECT @@VERSION"
# doit afficher la version de SQL Server 2022
✅ Identifiants SQL Server
Serveur : localhost,1433  |  Utilisateur : sa  |  Mot de passe : TestFlowAI@2024!

5 — Ollama (IA locale)

Télécharger : https://ollama.com/download → choisir Windows.

Après installation, démarrer le serveur Ollama :

ollama serve
# Laisser ce terminal ouvert — le serveur tourne sur http://localhost:11434

Télécharger un modèle selon votre RAM

Modèle Taille RAM requise Recommandé pour
phi3 ~2.3 Go 8 Go PC avec peu de RAM
mistral ~4.1 Go 8 Go Bon équilibre qualité/vitesse
llama3 ~4.7 Go 16 Go Meilleure qualité (recommandé) 
# Dans un nouveau terminal (garder ollama serve ouvert dans l'autre)
ollama pull llama3      # ou : mistral / phi3

# Tester le modèle
ollama run llama3 "Génère un cas de test pour un watchdog timer embarqué"

# Vérifier que l'API HTTP répond
curl http://localhost:11434/api/tags

6 — IDE : Visual Studio Code

Télécharger : https://code.visualstudio.com

ℹ️ Vous pouvez aussi utiliser Visual Studio 2022 Community (gratuit) si vous préférez un IDE complet pour .NET : https://visualstudio.microsoft.com/fr/vs/community/

Extensions VS Code à installer

Ouvrir VS Code → Ctrl+Shift+X → rechercher et installer chacune :

Extension Rôle
C# Dev Kit IntelliSense, débogage et navigation pour .NET
ESLint Qualité et détection d'erreurs TypeScript/React
Prettier Formatage automatique du code
Thunder Client Tester les endpoints REST directement dans VS Code
Docker Gérer les conteneurs SQL Server depuis VS Code
GitLens Historique git avancé, blame, comparaisons

7 — Cloner et lancer le projet

Cloner le dépôt GitHub

git clone https://github.com/younes2013/testflow-ai.git
cd testflow-ai
git checkout claude/init-testflow-ai-project-fGbBt

Démarrer SQL Server

docker compose up -d

Lancer le back-end

cd src/TestFlowAI.API
dotnet restore
dotnet run

# API disponible sur : http://localhost:5000
# Swagger UI sur    : http://localhost:5000/swagger

Lancer le front-end (nouveau terminal)

cd frontend
npm install
npm run dev

# Application disponible sur : http://localhost:5173

Démarrer Ollama (nouveau terminal)

ollama serve
